# Quick Start

## docker

`git clone https://github.com/slawkens/myaac.git`

`cd myaac`

`cd docker/full && docker compose up --build`

More info and how to access your instance - [in the docker readme](https://github.com/slawkens/myaac/blob/develop/docker/README.md)
